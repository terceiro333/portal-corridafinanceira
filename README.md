# Corrida Financeira — Catálogo de versões

Site estático responsivo feito em HTML, CSS e JavaScript, sem precisar instalar nada.

## Abrir no computador

1. Extraia o arquivo ZIP.
2. Abra `index.html` no navegador. É importante manter os arquivos e a pasta `assets` juntos.

## Publicar gratuitamente no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `corrida-financeira-versoes`.
2. Envie **o conteúdo da pasta** (index.html, styles.css, script.js e pasta assets) para a raiz do repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch **main** e pasta **/(root)**.
5. Salve e abra o endereço disponibilizado pelo GitHub Pages.

## Atualizar as versões

As quatro versões estão em `index.html`, na seção `id="catalogo"`. Cada cartão contém o nome, a imagem em `assets/` e o link do jogo. O destaque da V2 fica na seção `id="inicio"`.

O site usa as imagens originais fornecidas. Não contém anúncios nem sistemas de cadastro.

Os Google Fonts são opcionais: sem conexão com a internet, o navegador usa fontes do sistema.

## Comparador V1 × V2

Clique em **Comparar versões** no menu. Arraste a linha vertical da imagem para a esquerda ou para a direita (também funciona com toque no celular e as setas do teclado). O botão **Centralizar** retorna a 50%. As capturas da V1 e da V2 são as imagens originais em `assets/`.
